# กู้ข้อมูลเครื่องจักรที่ QR เปิดไม่เจอบนเครื่องอื่น

## สาเหตุที่ตรวจพบ

เครื่องจักรบางรายการอยู่ใน `localStorage` ของเบราว์เซอร์แอดมิน แต่ยังไม่มีในฐานข้อมูล Production ดังนั้นเบราว์เซอร์เดิมจึงเห็นข้อมูล ขณะที่โทรศัพท์หรือเครื่องอื่นเปิด QR แล้วไม่พบเครื่อง การเปลี่ยน URL ระหว่าง `/app/` กับหน้าเว็บหลักไม่ทำให้ข้อมูลที่อยู่เฉพาะเครื่องถูกส่งขึ้น Cloud

QR ที่ผู้ใช้แจ้งถูกตรวจผ่าน `portal_open` ของฐานข้อมูล Production แล้วได้ `not_found` ณ วันที่ 6 ตุลาคม 2026 ไม่บันทึก token เต็มไว้ในเอกสารนี้ เพราะลิงก์ QR ใช้เข้าถึงข้อมูลเครื่อง

## วิธีแก้สำหรับผู้ใช้

1. ใช้ **เบราว์เซอร์เดิมที่ยังเห็นเครื่องจักร** เข้า [ระบบ Production `/app/`](https://imodeservice.github.io/ImodeService/app/) ด้วยบัญชีพนักงาน
2. ไปหน้า **เครื่องจักร** แล้วกด **☁ ซิงก์เครื่องที่ค้าง** เพียงครั้งเดียว ไม่ต้องเปิดแก้ไขและบันทึกทีละเครื่อง
3. อ่านผลในป๊อปอัป ระบบจะแจ้งจำนวนเครื่องที่ส่งขึ้น Cloud และตรวจ QR สำเร็จ รวมถึงรายการที่ไม่สำเร็จ
4. เปิด QR เดิมบนโทรศัพท์หรือเบราว์เซอร์อื่นเพื่อตรวจซ้ำ

**อย่าล้างข้อมูลเบราว์เซอร์เดิมก่อนซิงก์สำเร็จ** เพราะอาจเป็นที่เดียวที่ยังมีข้อมูลเครื่องที่ค้าง

## พฤติกรรมของปุ่ม

- อ่านรายการเครื่องใน Cloud ก่อน แล้วส่งเฉพาะเครื่องในเบราว์เซอร์ที่ Cloud ยังไม่มี โดยใช้ ID เดิม จึงไม่สร้างเครื่องซ้ำหรือเขียนทับเครื่องที่มีอยู่แล้ว
- ข้ามรายการที่ระบบบันทึกว่าเคยอยู่บน Cloud แล้วถูกลบ เพื่อไม่กู้เครื่องที่ลบโดยตั้งใจ
- หลังส่งแต่ละเครื่อง เรียก `portal_open` เพื่อตรวจว่า QR เปิดข้อมูลจาก Cloud ได้จริง
- หาก QR ในเบราว์เซอร์ไม่ตรงกับ QR ของเครื่อง ID เดียวกันบน Cloud ระบบแจ้งเตือนและไม่เปลี่ยน QR ของ Cloud
- หากการเชื่อมต่อ สิทธิ์ฐานข้อมูล หรือโครงสร้างตารางทำให้ส่งไม่สำเร็จ ป๊อปอัปจะแจ้งข้อผิดพลาด เครื่องนั้นยังอยู่ในเบราว์เซอร์เดิม
